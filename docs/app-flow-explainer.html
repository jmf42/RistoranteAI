Ristorante AI Flow Explainer

This explainer was updated for the OpenAI Realtime architecture. The old ElevenLabs-based version has been retired.

Current stack

  • Twilio receives the inbound phone call.
  • The backend resolves the restaurant and opens a media stream.
  • The backend orchestrates an OpenAI Realtime session.
  • Booking tools run on the backend against the main database.
  • The dashboard reads the same booking and call data.
